# Web quản lý box Lela — Implementation Plan (bản 2)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (anh Tiến chọn cách tiết kiệm: tự làm inline, duyệt 1 lần cuối). Steps use checkbox (`- [ ]`).

**Goal:** Web tĩnh để nhân viên Lela Box theo dõi 12 box lúc này, đặt trước (1–3 box/phiếu), cho khách vào / về, đếm giờ ngồi thêm, nhắc việc + chuông; Chủ xem báo cáo. Đêm 19/11 chạy thử trên máy (dữ liệu trong trình duyệt), SQL Supabase viết sẵn.

**Architecture:** HTML + JS thuần (ES modules, `#/...`), `html\`\`` tự thoát (chép từ Milano `docs/js/ui.js`). Logic thuần tách riêng (`time.js`, `rules.js`, `board.js`, `report.js`) chạy thử bằng `jsc -m`. Đồng hồ `clock.js` giả lập được (`?now=`). Lớp `store` hai bản cắm cùng giao diện: `local` (localStorage) / `supabase` (rpc `app_*`). Giao diện thử bằng Chrome headless.

**Tech Stack:** JS/CSS thuần, Python 3 `http.server`, Chrome headless, `jsc`, Postgres/Supabase (chưa chạy).

**Spec:** `tai_lieu/superpowers/specs/2026-11-19-dat-box-design.md` (bản 2)
