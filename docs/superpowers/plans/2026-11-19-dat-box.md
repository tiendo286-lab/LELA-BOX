# Web đặt box Lela — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web tĩnh cho nhân viên Lela Box xem lịch box theo giờ, tạo / sửa / đổi trạng thái phiếu, không bao giờ chồng giờ; chạy thử trên máy đêm 19/11 bằng bản cắm dữ liệu `local`, kèm SQL Supabase viết sẵn.

**Architecture:** HTML + JS thuần (ES modules, định tuyến `#/...`), mẫu HTML qua `html\`\`` tự thoát ký tự (chép từ Milano `docs/js/ui.js`). Lớp `store` có hai bản cắm cùng một giao diện: `local` (localStorage + dữ liệu mẫu) và `supabase` (gọi hàm `app_*`). Giao diện thử bằng Chrome headless như Milano.

**Tech Stack:** JS thuần, CSS thuần, Python 3 `http.server` (chạy thử), Chrome headless, `jsc` (JavaScriptCore), Supabase/Postgres (SQL viết sẵn, chưa chạy).

### Task 2: `rules.js` — chống trùng, kiểm phiếu, chuẩn hoá khách

**Files:** Create `docs/js/rules.js`, `kiem_tra/rules_test.mjs`.

**Interfaces — Consumes:** `time.js`. **Produces:**
- `HOLDS = ['dat','den','xong']`; `STATUS_LABEL = {dat:'Đã đặt',den:'Đã đến',xong:'Xong',huy:'Huỷ',vang:'Không đến'}`
- `findConflict(b, others: Booking[], cleanMin: number) -> Booking|null` — `b` = `{id?, boxId, date, startMin, endMin, status}`; bỏ qua `o.id === b.id`, khác box, khác ngày, `o` hoặc `b` không giữ giờ.
- `validateBooking(b, settings, box) -> string|null` — câu lỗi tiếng Việt hoặc null. Thứ tự kiểm: thiếu tên khách "Nhập tên khách"; thiếu box/ngày/giờ; `endMin<=startMin` "Giờ kết thúc phải sau giờ bắt đầu"; không chia hết 30 "Giờ phải theo bước 30 phút"; ngoài cửa sổ "Ngoài giờ mở cửa (08:00–01:00)"; `box.active===false` "Box này đang ngừng dùng"; `people > box.capacity` → **không lỗi** (chỉ cảnh báo ở giao diện).
- `conflictText(o, boxName) -> string` → `"Trùng với phiếu của Lan, Box 1, 09:00–11:00"`
- `normPhone(s) -> string` (chỉ giữ chữ số; `+84` đầu → `0`), `normTiktok(s) -> string` (bỏ `@` và khoảng trắng, chữ thường)
- `sameCustomer(a, b) -> boolean` (cùng normPhone khác rỗng, hoặc cùng normTiktok khác rỗng)
